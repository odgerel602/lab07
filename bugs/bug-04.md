# BUG-04: Ном нэмэхэд валидаци байхгүй: хоосон талбар, үсэгтэй/бутархай он хүлээн авагдаж «NaN» гэж харагддаг

Орчин: Уншлагын жагсаалт v2.0, Firefox 144.0 + curl.exe, Windows 11, Node v24.21.0, 2026-10-17 (curl evidence 2026-11-19)
Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам
1. http://localhost:3000 нээнэ.
2. Гарчиг, Зохиолч талбарыг хоосон орхиж, Он: `abc` гэж бичээд «Нэмэх» дарна.
3. Мөн Он: `9,00` гэж бичээд нэмнэ.
4. API-аар шалгах: `curl.exe -i -X POST http://localhost:3000/api/books -H "Content-Type: application/json" -d "{\"title\":\"\",\"author\":\"\",\"year\":\"abc\"}"`

Хүлээгдэж байсан: Гарчиг, Зохиолч заавал бөглөгдөх ба Он нь бүхэл тоо, зөвшөөрөгдсөн хүрээнд (жишээ нь 1000–2100) байх ёстой. Буруу оролтод алдааны мессеж гарч, API 400 буцаах ёстой.
Бодит үр дүн: UI-д «Ном нэмэгдлээ» мессеж гарч, гарчиг/зохиолч хоосон, он нь «NaN» гэсэн мөр нэмэгдсэн. API `HTTP/1.1 201 Created` буцааж, `{"id":4,"title":"","author":"","year":"abc"}` гэж хадгалсан. 999, 2101 зэрэг хүрээнээс гадуурх он ч хүлээн авагддаг.
Ноцтой байдал: Major (буруу өгөгдөл хадгалагдаж, хүснэгтэд «NaN» гарч, «Нийт ном» тоонд нөлөөлнө)
