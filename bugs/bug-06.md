# BUG-06: Хайлт том/жижиг үсэг ялгадаг тул «clean» гэж хайхад «Clean Code» олдохгүй

Орчин: Уншлагын жагсаалт v2.0, Firefox 144.0 + curl.exe, Windows 11, Node v24.21.0, 2026-10-17 (curl evidence 2026-11-19)
Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном, «Clean Code» орсон)

## Дахин гаргах алхам
1. http://localhost:3000 нээнэ.
2. «Хайх үг» талбарт `clean` гэж бичээд «Хайх» дарна.
3. Дараа нь `Clean` гэж бичээд дахин «Хайх» дарна.

Хүлээгдэж байсан: Хайлт том/жижиг үсэг ялгахгүй байж, хоёр тохиолдолд «Clean Code» олдох ёстой.
Бодит үр дүн: `clean` → хүснэгт хоосон (`GET /api/books?q=clean` нь `[]`), `Clean` → «Clean Code» олдоно. Хайлт олдоогүй үед «олдсонгүй» гэх мессеж ч гарахгүй, хүснэгт зүгээр хоосорно.
Ноцтой байдал: Minor (хайлт ажиллана, гэхдээ хэрэглэгч номоо олж чадахгүй байх магадлалтай)
