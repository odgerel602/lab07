# BUG-07: Ном устгахад «Ном нэмэгдлээ» гэсэн буруу мессеж гардаг; «Устгах» товч ногоон өнгөтэй

Орчин: Уншлагын жагсаалт v2.0, Firefox 144.0, Windows 11, Node v24.21.0, 2026-10-17
Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам
1. http://localhost:3000 нээнэ.
2. «Clean Code» мөрийн «Устгах» товч дээр дарна.
3. Хүснэгтийн дээрх мессежийг уншина.

Хүлээгдэж байсан: «Ном устгагдлаа» гэх мэт устгах үйлдэлд тохирох мессеж гарах. Устгах (буцаах боломжгүй) үйлдлийн товч нь анхааруулах (улаан) өнгөтэй байх, баталгаажуулах асуулт гарах.
Бодит үр дүн: Ном устгагдсан ч «Ном нэмэгдлээ» гэсэн мессеж гарсан. «Устгах» товч ногоон (#2C7A4B) өнгөтэй тул «зөвшөөрөх/нэмэх» үйлдэл мэт харагдана. Баталгаажуулах асуултгүйгээр шууд устгана.
Ноцтой байдал: Minor (өгөгдөл зөв устгагдана, гэхдээ хэрэглэгчийг төөрөгдүүлнэ)
Хавсралт: Скриншот байхгүй; апп-ийн эх кодын `delBook()` функц болон `.del` CSS классаар баталгаажна.
Олдсон аялал: Supermodel (GUI)
