# BUG-05: Footer дээрх «Хуучин хувилбар» холбоос 500 Internal Server Error буцаадаг

Орчин: Уншлагын жагсаалт v2.0, Firefox 144.0 + curl.exe, Windows 11, Node v24.21.0, 2026-10-17 (curl evidence 2026-11-19)
Урьдчилсан нөхцөл: node app.js ажиллаж байгаа

## Дахин гаргах алхам
1. http://localhost:3000 нээнэ.
2. Хуудасны доод хэсэгт байх «Хуучин хувилбар» холбоос дээр дарна (эсвэл `curl.exe -i http://localhost:3000/old`).

Хүлээгдэж байсан: Аппын хуучин хувилбар нээгдэх, эсвэл хуудас байхгүй бол холбоос харагдахгүй байх.
Бодит үр дүн: `HTTP/1.1 500 Internal Server Error`, хуудсанд зөвхөн «Internal Server Error» гэсэн текст гарна. Хэрэглэгчид ямар ч тайлбар өгөхгүй, буцах холбоосгүй.
Ноцтой байдал: Minor (үндсэн функц ажиллана, гэхдээ харагдаж буй холбоос эвдэрхий)
