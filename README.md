## Тойм

Энэ репо нь «Уншлагын жагсаалт» вэб апп дээр хийсэн session-based exploratory тестийн ажил юм.

- charter.md: session-ээс өмнө бичсэн charter
- session-report.md: 60 минутын session-ий тайлан
- bugs/: алдааны тайлангууд
- evidence/: API согогийн curl -i гаралт
- screenshots/: UI согогийн скриншот

Тэмдэглэл: app.js нь багшийн өгсөн файл тул энэ репод оруулаагүй.

**Эрсдэл, дүгнэлт.** Хамгийн ноцтой асуудал нь оролтын валидаци огт байхгүй байгаа явдал (BUG-02, 03, 04): буруу, давхардсан өгөгдөл хадгалагдаж, API алдааг нуун «OK» гэж хариулдаг. Иймд аппыг одоогийн байдлаар хэрэглээнд гаргахад бэлэн биш гэж үзэж байна. Засварын дараалал: (1) сервер талд валидаци ба 400 хариу, (2) давхардлын шалгалт, (3) тоолуур, мессеж, хайлтын UI согогууд.

**Юу хамрагдаагүй бэ.** Маш урт гарчиг, тусгай тэмдэгт (`<script>` гэх мэт), хоёр цонхоор зэрэг ажиллах, DELETE API-г байхгүй id-аар дуудах зэргийг цаг хүрэлцээгүй тул бүрэн шалгаж амжаагүй. Дараагийн session-д эдгээрийг charter болгон авах нь зүйтэй.

**Session-ий тухай.** Цагийн 60% нь тест гүйцэтгэлд, 30% нь согог судлах, баримтжуулахад зарцуулагдсан. PowerShell-ийн `curl` alias болон UTF-16 гаралт зэрэг хэрэгслийн саад цаг авсан тул дараагийн удаа `curl.exe`-г шууд ашиглах, evidence-г UTF-8-аар хадгалах хэрэгтэй.
